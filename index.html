Course map

A path from bytes to threads

The material moves from representation and pointers into generic data structures, low-level machine behavior, and finally concurrent programs.

Lec 01-04

Foundations

C memory layout, pointers, casts, and generic pointer techniques.

Lec 05-08

Data and Memory

Concurrency

Lecture notes

Jump into the notes

01 Programming Paradigms Procedure, object-oriented, functional, and concurrent styles. 02 C Programming Binary representation, integer behavior, floats, and casts. 03 C Pointer Pointers, arrays, structs, offsets, and pointer-based swap. 04 Generic Pointer Void pointers, callbacks, generic swap, search, and sorting. 05-07 Generic Data Structure Build a reusable stack and reason through generic operations. 08 Stack and Heap Allocation internals, stack frames, heap managers, and fragments. 09 Assembly Language Instructions, registers, branches, arrays, and low-level casts. 10 Activation Records Function frames, saved PC, return values, and recursion. 11 C++ References and Classes References, classes, methods, this pointers, and static members. 12 Preprocessing Macros, include rules, header guards, and preprocessing stages. 13 Compiling and Linking Object files, libraries, runtime crashes, and buffer overflow. 14 More Assembly Printf, structs, process switching, and virtual address spaces. 15 Ticket Agent Threads, scheduling, shared resources, semaphores, and deadlock. 16 Semaphore Patterns Semaphores as locks, ring buffers, and coordination primitives. 17 Dining Philosophers Deadlock avoidance, busy waiting, and multi-threaded downloads. 18 Ice Cream Store Simulation A larger concurrency simulation with managers, clerks, and cashiers.
